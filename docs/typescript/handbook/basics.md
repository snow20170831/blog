## tsc（typesctipt 编译器）

我们一直在讨论类型检查，但还没有使用过类型检查器。让我们来认识一下我们的新朋友 tsc - TypeScript 编译器。首先，我们需要通过 npm 安装它。

```sh
npm install -g typescript
```

::: tip
上述命令将全局安装 TypeScript 编译器 tsc。如果你想从本地的 node_modules 包运行 tsc，可以使用 npx 或类似工具。
:::
